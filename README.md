# IGNIS — Flame in Freefall

Рабочее место по пожарной безопасности обитаемых модулей на данных NASA PSI. Проект команды sulateam для NASA Space Apps Challenge 2026.

24 исследования о горении в невесомости, 22 таблицы испытаний, 135 документов и сырые записи датчиков сведены в одну SQLite-базу. Сайт показывает, какие опыты ближе всего к атмосфере МКС, лунной базы, ровера, Марса или скафандра, где данных нет совсем, и отвечает на вопросы только по архиву — со ссылкой на файл, строку таблицы или страницу PDF.

## Запуск

```bash
./run.sh setup    # зависимости Python и Node
./run.sh serve    # сайт на http://127.0.0.1:8000, API-документация на /docs
```

Для работы нужны только `data/ignis.db` (16 МБ) и собранный `frontend/dist`. Остальные команды:

```bash
./run.sh build    # пересобрать data/ignis.db из ../pre_nasa (--no-pdf — без текста PDF, быстрее)
./run.sh web      # собрать фронтенд
./run.sh dev      # API на :8000 и Vite с горячей перезагрузкой на :5173
```

## Что на сайте

| Раздел | Что делает |
| --- | --- |
| Обзор | Модель пламени для выбранной среды, карта «давление — кислород» со всеми испытаниями, пять самых полезных исследований, запись пожара Saffire-III, быстрые ответы |
| Исследования | Сортировка под среду с прозрачным баллом из четырёх частей, поиск по теме на русском и английском, фильтры |
| Атмосфера | Калькулятор: кислород, давление, гравитация, поток → pO₂, предупреждения, ближайшие строки таблиц; параметры в URL |
| Телеметрия | Шесть полётных записей с воспроизведением, распределение частиц дыма 0 g / 1 g, наборы данных для моделирования в CSV |
| Сравнение | До четырёх исследований рядом с отметкой различий |
| Таблицы | Все таблицы PSI как есть: просмотр, фильтр, CSV, вопрос по таблице |
| Ассистент | Ответы по архиву со ссылками [n] и проверкой чисел |

`Ctrl K` открывает быстрый переход к любому исследованию, таблице или разделу.

## Как проверяются ответы ассистента

Вопрос → поиск по базе (`backend/search.py`: FTS5 и русско-английский глоссарий) → модель получает только найденные фрагменты и обязана ссылаться на них `[n]` → код проверяет, что ссылки существуют и что каждое число ответа есть в источниках. Если модель не сослалась ни на что или недоступна, показываются сами фрагменты. Сайт работает и без ключа модели.

## Настройка

Переменные читаются из окружения или `.env`:

| Переменная | Назначение |
| --- | --- |
| `OPENROUTER_API_KEY` | ключ OpenRouter для ассистента |
| `OPENROUTER_MODELS` | модели через запятую; опрашиваются по две, берётся первый пригодный ответ |
| `IGNIS_DATA_ROOT` | путь к сырому архиву PSI (по умолчанию `../pre_nasa`), нужен только для `build` |
| `IGNIS_DB` | путь к базе (по умолчанию `data/ignis.db`) |
| `HOST`, `PORT` | адрес сервера для `run.sh` |

## Структура

```
backend/
  build.py       сборка базы: карточки, таблицы, файлы, тексты PDF, поисковый индекс
  normalize.py   правила для каждой таблицы: кислород в %, давление в кПа, поток, даты, топливо
  curated.py     двуязычные описания исследований, среды экипажа, применения на Земле, глоссарий
  faq.py         быстрые ответы; числа считаются из таблиц при сборке
  telemetry.py   полётные записи датчиков, распределения дыма, таблицы для моделирования
  scoring.py     балл близости к среде и расчёт атмосферы
  search.py      поиск, ближайшие испытанные условия, ранжирование исследований
  ai.py          вызов модели и проверка ответа
  app.py         FastAPI: /api/* и раздача сайта
frontend/src/
  api.ts         типы ответов API и клиент
  i18n.ts        все тексты интерфейса на русском и английском, форматирование чисел и дат
  store.tsx      маршрутизация, язык, выбранная среда, список сравнения
  components/    пламя, карта атмосферы, телеметрия, окно таблицы, ответы ассистента, общие элементы
  pages/         по файлу на раздел
data/ignis.db    готовая база
```
